Eingriff. Drei Teile in der Bibliothek, für jede gesteuerte Figur. Erstens: Das Bein eines schwingenden Fußes kommt
bremsend auf die Länge, mit der es landet, höchstens auf seine Reichweite. Es wird in einem Update nur um so viel
länger, dass es mit einer Verzögerung von NB_LEG_BRAKE, 45 m/s² für eine Figur der Größe 1, an dieser Länge zum Stehen
kommt; sein Knöchel bleibt dafür auf der Linie von der Hüfte zu seiner Bahn zurück. Bisher hielt eine harte Grenze das
Bein an seiner Reichweite an. Zweitens: Ein Fuß, der landet, bevor sein Bein so weit ist, kommt in den nächsten ein bis

höchstens mit dem Fersenrollen, auf das sein Schwung gekommen ist. Neu sind die Konstante NB_LEG_BRAKE und drei Felder
